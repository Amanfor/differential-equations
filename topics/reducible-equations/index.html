Clairaut’s form

y=xp+f(p),p=dydxy = xp + f(p), \quad p = \frac{dy}{dx}y=xp+f(p),p=dxdy​

differentiate with respect to xxx:

dydx=p=p+xdpdx+f′(p)dpdx  ⟹  dpdx[x+f′(p)]=0\frac{dy}{dx} = p = p + x\frac{dp}{dx} + f'(p)\frac{dp}{dx} \implies \frac{dp}{dx}\left[x + f'(p)\right] = 0dxdy​=p=p+xdxdp​+f′(p)dxdp​⟹dxdp​[x+f′(p)]=0

Branch A (general solution): dpdx=0  ⟹  p=C\frac{dp}{dx} = 0 \implies p = Cdxdp​=0⟹p=C.

y=Cx+f(C)(family of straight lines)y = Cx + f(C) \quad \text{(family of straight lines)}y=Cx+f(C)(family of straight lines)

Branch B (singular solution): x+f′(p)=0x + f'(p) = 0x+f′(p)=0.
