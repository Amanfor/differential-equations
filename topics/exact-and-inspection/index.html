before any formula — what is “exact”?

an expression M(x,y) dx+N(x,y) dyM(x,y)\,dx + N(x,y)\,dyM(x,y)dx+N(x,y)dy is an exact differential if there exists a function u(x,y)u(x,y)u(x,y) such that

du=∂u∂xdx+∂u∂ydy=M dx+N dydu = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy = M\,dx + N\,dydu=∂x∂u​dx+∂y∂u​dy=Mdx+Ndy

this happens iff ∂M∂y=∂N∂x\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}∂y∂M​=∂x∂N​ (mixed partials are equal).

when exact, the solution is simply u(x,y)=Cu(x,y) = Cu(x,y)=C.

typical mistakes

  1. thinking any M dx+N dyM\,dx + N\,dyMdx+Ndy is exact. always check ∂M/∂y=∂N/∂x\partial M/\partial y = \partial N/\partial x∂M/∂y=∂N/∂x first. ::

  2. not spotting x dy+y dx=d(xy)x\,dy + y\,dx = d(xy)xdy+ydx=d(xy) because the terms are separated. always look for x dyx\,dyxdy and y dxy\,dxydx together. ::

  4. confusing x dy−y dxx2=d(y/x)\frac{x\,dy - y\,dx}{x^2} = d(y/x)x2xdy−ydx​=d(y/x) with y dx−x dyy2=d(x/y)\frac{y\,dx - x\,dy}{y^2} = d(x/y)y2ydx−xdy​=d(x/y). the signs matter. ::
