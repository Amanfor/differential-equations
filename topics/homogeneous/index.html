topics / homogeneous equations (y = vx)

before any formula — what does “homogeneous” mean here?

a function f(x,y)f(x, y)f(x,y) is homogeneous of degree nnn if f(λx,λy)=λnf(x,y)f(\lambda x, \lambda y) = \lambda^n f(x, y)f(λx,λy)=λnf(x,y).

a first-order equation is homogeneous if the RHS is a function of the ratio y/xy/xy/x only:

dydx=f(x,y)g(x,y)=F(yx)\frac{dy}{dx} = \frac{f(x, y)}{g(x, y)} = F\left(\frac{y}{x}\right)dxdy​=g(x,y)f(x,y)​=F(xy​)

where fff and ggg are homogeneous polynomials of the same degree.

the substitution y=vxy = vxy=vx — why it works

if the equation only sees y/xy/xy/x, then let v=y/xv = y/xv=y/x. the equation becomes a function of vvv only:

y=vx  ⟹  dydx=v+xdvdxy = vx \implies \frac{dy}{dx} = v + x\frac{dv}{dx}y=vx⟹dxdy​=v+xdxdv​

substitute:

v+xdvdx=F(v)  ⟹  xdvdx=F(v)−v  ⟹  dvF(v)−v=dxxv + x\frac{dv}{dx} = F(v) \implies x\frac{dv}{dx} = F(v) - v \implies \frac{dv}{F(v) - v} = \frac{dx}{x}v+xdxdv​=F(v)⟹xdxdv​=F(v)−v⟹F(v)−vdv​=xdx​

now the variables are separated: vvv on the left, xxx on the right.

common mistakes

typical mistakes

  1. using y=vxy=vxy=vx when the equation is not homogeneous. the RHS must be a function of y/xy/xy/x only. ::

  2. forgetting the product rule: y′=v+xv′y' = v + xv'y′=v+xv′, not just v′v'v′. ::

  3. in case 1 (intersecting lines), solving for h,kh,kh,k but then forgetting to shift back to x,yx,yx,y at the end. ::

  4. in case 2 (parallel lines), trying y=vxy=vxy=vx instead of the substitution t=a2x+b2yt = a_2x + b_2yt=a2​x+b2​y. ::

  5. sign error when separating: xdvdx=F(v)−vx\frac{dv}{dx} = F(v) - vxdxdv​=F(v)−v, not v−F(v)v - F(v)v−F(v). ::
